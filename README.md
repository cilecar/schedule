# Schedule Bot

Telegram-бот с расписанием пар и домашними заданиями для учебной группы. Написан на **aiogram 3**,
данные хранит в **MongoDB**.

## Возможности

- 📅 Расписание на сегодня и на завтра, 📖 полное расписание (с учётом чётности недели)
- 📝 Домашние задания: добавление, прикрепление файлов, смена статуса, просмотр
- 🔔 Вечером присылает расписание на завтра, напоминает о дедлайнах. Время настраивается
- ⚙️ Пользовательские настройки уведомлений
- Админ может разослать сообщение всем пользователям (`/send_global_message`)
  и добавить ссылку на пару

## Структура

```
main.py            точка входа
config.py          конфиг из .env
handlers/          обработчики (расписание, ДЗ, настройки, база)
keyboards/         reply- и inline-клавиатуры
services/          фоновые задачи, логирование, утилиты
database/db.py     работа с MongoDB
data/              данные расписания
```

## Запуск

```sh
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать токен бота, MONGO_URI, ADMIN_ID
python3 main.py
```

Токен бота выдаёт [@BotFather](https://t.me/BotFather).

## Деплой
